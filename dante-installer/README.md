# install_dante_proxy.py

Идемпотентный установщик SOCKS5-прокси (Dante) на Debian 12/13 для парка VPS.

Написан потому, что `dante-server` **удалён из Debian 13 (trixie)** — в bookworm пакет есть, в trixie его нет. На Debian 12 установка занимает минуту, на Debian 13 нужна компиляция из исходников. Скрипт делает и то и другое автоматически.

## Что делает

1. Подключается по SSH к каждому серверу из `servers.txt`.
2. Чистит старые прокси-сервисы (microsocks, danted).
3. Ставит Dante: `apt` на Debian 12, при отсутствии пакета — сборка из исходников с подходящими `CFLAGS` для GCC 14.
4. Валидирует конфиг **до** запуска (`danted -Vf`).
5. Настраивает systemd-юнит с явным PID-файлом, `Restart=always`, лимитами памяти и дескрипторов.
6. Блокирует через прокси частные и специальные сети (RFC1918, loopback, link-local, CGNAT) **и собственные IP сервера**, чтобы нельзя было достучаться до его же sshd.
7. Ставит healthcheck по таймеру: проверяет SOCKS-рукопожатие и перезапускает сервис при отказе.
8. Проверяет результат: рукопожатие → выход наружу через прокси → отказ при неверном пароле (не открытый ли прокси) → блокировка внутренних адресов.
9. Пишет креды в файл с правами `0600`, атомарно, с меткой прогона.

## Ключевые решения

- **`policy-rc.d` на время установки пакета.** Без этого postinst пакета поднимает danted с дефолтным конфигом, и получается гонка «сервис запущен раньше конфига».
- **Положительный контроль до негативного.** `curl` с кодом 97 (CURLE_PROXY) означает и «сработало правило блокировки Dante», и «не прошла авторизация». Поэтому сначала доказывается, что выход наружу с этими кредами работает, и только потом проверяется блокировка — иначе результат неоднозначен.
- **Пароль резервируется на диск сразу после `chpasswd`,** до остальных шагов: если прогон упадёт посередине, пароль не потеряется.
- **Один `apt-get update` на сервер** и ровно один фолбэк на сборку из исходников.

## Использование

```
servers.txt — по строке на сервер:
IP:SSH_ПАРОЛЬ:ПАРОЛЬ_ПРОКСИ     (пароль прокси можно оставить пустым — сгенерируется)
```

Перед первым запуском вписать `DANTE_SHA256` (см. ниже) и проверить `TEST_URLS`.

```bash
pip install paramiko
python install_dante_proxy.py
```

Результат: `proxies_final_dante.txt` (формат `ip:port:user:password`) и `proxies_recovery.txt` — пароли изменённых серверов, страховка от прерывания.

## Требования к конфигурации

- `DANTE_VERSION` и **обязательный** `DANTE_SHA256` — хеш архива. Скрипт откажется собирать из непроверенного архива. Посчитать: `sha256sum dante-1.4.3.tar.gz`.
- `TEST_URLS` — три цели для проверки выхода: домен, IP-сервис, адрес по IP без DNS.

## Известные ограничения

- Нет rate limit на порту прокси — при публичном порте стоит закрыть это правилом nftables или fail2ban.
- Пересборка выполняется на каждом сервере. Для парка это медленно: правильнее один раз собрать `.deb` (`checkinstall`) и раздавать его через `dpkg -i`.
- `DenyUsers` для служебного пользователя пишется в `sshd_config.d`; если в `sshd_config` нет директивы `Include`, файл не применяется — это надо проверять.
